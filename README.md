## 目录结构

```
ai-optimization-solutions/
└── docs/
    ├── AI编程工具-Skills/         # AI 编程工具与 Skills 技能包
    ├── Agent智能体设计/           # Agent 智能体架构与设计模式
    ├── 记忆系统Memory/            # Agent 记忆系统与持久化方案
    ├── RAG检索增强/               # RAG 检索增强与优化实战
    ├── LLM网关架构/               # LLM 网关与生产级架构
    └── AI工具/                    # AI 相关工具与开源项目
```

每篇文章目录下包含：
- `原文.md` — 原始文章内容
- `总结.md` — 整理后的核心要点
