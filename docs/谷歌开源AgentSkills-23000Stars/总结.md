# 谷歌开源 Agent Skills - 23000+ GitHub Star

> 总结使用: MiniMax M2.5

## 核心概念

Agent Skills 由谷歌 Gemini 团队主管 Addy Osmani 开源，将资深工程师的工作流和开发规范封装成 Skills 技能包。

**背后理论**：源自《Software Engineering at Google》，Google 内部大规模软件工程方法论。

## 技能包组成

| 类型 | 数量 | 说明 |
|------|------|------|
| Skill | 20个 | 可组合的工程技能 |
| Slash命令 | 7个 | 快速调用开发命令 |
| Agent人设 | 3个 | code-reviewer、test-engineer、security-auditor |

## 覆盖开发链路

```
定义 → 规划 → 构建 → 验证 → 评审 → 发布
```

### Slash 命令

| 命令 | 功能 |
|------|------|
| /spec | 需求梳理 |
| /plan | 任务拆分 |
| /build | 增量实现 |
| /test | 运行测试 |
| /review | 代码评审 |
| /ship | 部署上线 |

### 上线检查流程

/ship 时三个 Agent 并行开工：
1. **code-reviewer** - 代码评审报告
2. **test-engineer** - 测试报告
3. **security-auditor** - 安全评估报告

最终给出是否可以上线的结论。

## 与同类工具对比

| 工具 | 理念 |
|------|------|
| Spec Kit | 用文档定 AI |
| Superpowers | 用流程带 AI |
| Agent Skills | 用纪律管 AI |

## 快速上手

**Claude Code:**
```
/plugin marketplace add addyosmani/agent-skills/plugin
plugin install agent-skills@addy-agent-skills
```

**Cursor:**
复制 SKILL.md 到 .cursor/rules/ 目录

还支持 Gemini CLI、Windsurf、GitHub Copilot、Codex 等工具。

## 总结

Agent Skills 的意义：没有让 AI 更聪明，而是把资深工程师的工程习惯沉淀下来，让 AI 每个开发环节都有规可循。
