# Transformer 注意力机制总结

## 核心要点

### 1. 注意力机制原理
- 灵感来源：人类视觉聚焦行为
- 核心思想：根据相关性动态分配注意力权重
- 类比：图书馆检索系统（Q=关键词，K=标签，V=内容）

### 2. 自注意力机制（Self-Attention）
- **核心公式**：`Attention(Q,K,V) = softmax(Q·K^T/√d_k) · V`
- **Q/K/V来源**：全部来自同一输入序列
- **作用**：让每个 token 都能与序列中所有其他 token 建立联系
- **解决的问题**：长距离依赖、无需逐层传递信息

### 3. 缩放点积注意力
- **计算步骤**：
  1. 线性映射生成 Q/K/V
  2. Q·K^T 计算相似度
  3. 除以 √d_k 缩放（防梯度消失）
  4. Softmax 归一化
  5. 加权求和生成输出

### 4. 多头注意力（Multi-Head Attention）
- **核心思想**：多个"头"从不同角度理解文本
- **公式**：`MultiHead = Concat(head_1,...,head_h) · W^O`
- **头数配置**：原始论文 h=8, d_k=64
- **各头可关注**：语法结构、语义关系、情感倾向等不同维度

### 5. 前馈神经网络（FFN）
- **结构**：两层线性变换 + ReLU 激活
- **作用**：对每个位置独立非线性变换，增强表达能力

### 6. 编码器-解码器架构
| 组件 | 编码器 | 解码器 |
|------|--------|--------|
| 第一层 | 多头自注意力 | 掩码多头自注意力 |
| 第二层 | 前馈网络 | 交叉注意力（看编码器） |
| 第三层 | - | 前馈网络 |

### 7. Transformer 三大核心优势
| 优势 | 说明 |
|------|------|
| 并行计算 | 一次处理全序列，GPU 利用率高 |
| 长距离依赖 | 任意位置直接关联，无衰减 |
| 可解释性 | 注意力权重可视化 |

### 8. 注意力机制的本质
> 用数学方法模拟人类的选择性关注，通过 Q/K/V 的相关性计算，动态聚焦关键信息，高效融合全局语义。
