# 腾讯开源Agent Memory - 核心要点总结

## 项目概述
TencentDB Agent Memory 是腾讯云数据库团队开源的 AI Agent 长期记忆框架，通过**上下文卸载 + Mermaid任务画布**技术，为Agent提供本地化长期记忆能力。

## 核心能力

### 1. Mermaid 任务画布
- 用 Mermaid Flowchart 将任务执行过程组织成结构化任务图
- Agent只需知道"哪些信息重要、它们组织在哪里、如何展开"
- 历史变成可继续执行的地图——能折叠也能展开

### 2. 四层递进上下文卸载
| 层级 | 内容 | 存储位置 |
|------|------|----------|
| L0 | 完整工具返回原文 | refs/*.md |
| L1 | 工具调用级摘要 | offload.jsonl |
| L2 | 任务画布节点 | *.mmd |
| L3 | 任务级索引（目标+状态） | 上下文 |

**核心原则**：底层保留证据，高层保留结构，任何一层压缩都不是不可逆的黑盒
