# LLM Wiki v0.4.11 发布：本地 API 让知识库接入任意 AI Agent

> 一个能自我构建的个人知识库，正在以惊人的速度进化。

今天，LLM Wiki 迎来了 v0.4.11 版本的发布，同时项目 Star 数也正式突破 **8,000**！从 Karpathy 的一个方法论 Gist 起步，到如今成为 GitHub 上最受关注的知识库项目之一，LLM Wiki 的成长有目共睹。

## v0.4.11 三大更新亮点

### 本地 API Server：知识库开放接入

这是本次更新最重磅的功能。LLM Wiki 现在内置了完整的 HTTP API Server（监听 127.0.0.1:19828），支持 Token 鉴权，提供了以下接口：

- **文件读取** — 获取项目文件树与 wiki 页面内容
- **混合搜索** — 关键词 + 向量语义的 Hybrid 检索
- **知识图谱数据** — 获取 Wikilinks 关系图谱
- **资料重扫** — 触发后端重新扫描源文件

这意味着什么？**你的知识库不再是孤岛。**

配合官方发布的 Agent Skill，只需一行命令就能把 Claude Code、Codex、Hermes Agent 等 AI 编程助手接入你的知识库：

```bash
npx skills add https://github.com/nashsu/llm_wiki_skill.git --skill llm_wiki_skill
```

安装之后，Agent 就能理解「我的知识库里关于 X 是怎么说的」「帮我搜一下 Y」「展示我 wiki 图谱中 Z 的邻居」这类指令——所有查询都在本地完成，数据不出本机。

在 **设置 → API 服务** 中即可开启并生成 Token，默认只读，安全可控。

### 统一搜索架构：关键词 + 向量，Rust 驱动

v0.4.11 将 UI 搜索和 API 搜索统一到了 Rust 后端，背后是一套完整的多阶段检索管线：

1. **分词搜索** — 英文分词 + 中文 CJK 二元组分词，标题匹配额外加分
2. **向量语义搜索（可选）** — 基于 LanceDB 的嵌入式向量数据库，支持任意 OpenAI 兼容的 Embedding 端点
3. **图谱扩展** — 基于四信号关联度模型（直接链接、来源重叠、Adamic-Adar、类型亲和）做 2 跳遍历
4. **预算控制** — 可配置 4K～1M tokens 上下文窗口
5. **上下文组装** — 按关联度排序，完整页面内容 + 编号引用

统一后的好处很明显：无论是 UI 中搜索还是 API 调用，检索质量完全一致。向量搜索开启后，整体召回率从 58.2% 提升至 71.4%。

### 知识图谱新增搜索：图谱检索更方便

知识图谱一直是 LLM Wiki 的亮点功能——基于四信号关联度模型 + Louvain 社区检测，它能把知识之间的隐藏关系可视化出来。

v0.4.11 在知识图谱中新增了**搜索功能**，你可以在图谱中直接搜索特定实体或概念，图谱会自动定位并高亮目标节点及其关联网络，大大提升了浏览体验。再配合「惊奇连接」与「知识空白」检测，系统能主动告诉你哪些知识点之间存在意外关联、哪些领域还缺少连接。

## LLM Wiki 使用教程：从零搭建你的知识库

### 一、快速开始：创建第一个项目

LLM Wiki 是一个**跨平台桌面应用**（基于 Tauri v2），它的核心理念与传统 RAG 完全不同——不是每次查询都临时去资料里翻找，而是让 LLM **增量构建并持续维护一个结构化的 Wiki 知识库**。知识只编译一次，持续更新，每次查询都能在整理好的知识网络中寻找答案。

**第一步：安装与启动**

从 Releases 页面下载对应系统的安装包：

| 系统 | 安装包 |
|---|---|
| macOS | LLM.Wiki_*_aarch64.dmg（Apple Silicon）或 LLM.Wiki_*_x64.dmg（Intel） |
| Windows | LLM.Wiki_*_x64_en-US.msi 或 LLM.Wiki_*_x64-setup.exe |
| Linux | LLM.Wiki_*_amd64.deb（Ubuntu/Debian）或 LLM.Wiki_*_amd64.AppImage |

安装后启动，你会看到三栏布局的界面：左侧知识树/文件树，中间聊天区域，右侧预览面板。

**第二步：创建项目与选择模板**

点击创建新项目，LLM Wiki 提供了多种场景模板供你选择：

- **研究模板** — 适合学术研究、论文阅读
- **阅读模板** — 适合读书笔记、文章剪藏
- **个人成长模板** — 适合个人知识体系搭建
- **商业模板** — 适合行业分析、竞品研究
- **通用模板** — 无预设方向，自由发挥

每个模板会自动生成 purpose.md（Wiki 的目标和方向）和 schema.md（Wiki 的结构规则），LLM 在每次处理都会参考它们。

**第三步：配置 LLM 提供商**

进入左侧边栏的**设置**（齿轮图标），配置你的 LLM API：

- **提供商**：支持 OpenAI、Anthropic、Google（Gemini）、Ollama（本地模型），以及任意兼容 OpenAI 接口的自定义端点
- **API 密钥**：填入你的 Key
- **模型选择**：根据需求选择模型
- **上下文窗口**：可滑动调节 4K～1M tokens，按比例分配 Wiki 页面、聊天历史和系统提示

建议首次使用选择 GPT-4o 或 Claude Sonnet 这类能力强且稳定的模型。

### 二、资料导入：喂给 LLM 的原材料

LLM Wiki 支持**十余种文件格式**：

| 格式 | 说明 |
|---|---|
| PDF | Rust 引擎 pdf-extract 高效提取 |
| DOCX | 保留标题、加粗/斜体、列表、表格结构 |
| PPTX | 逐页提取，保留标题与列表结构 |
| XLSX / XLS / ODS | 正确解析单元格类型，多工作表支持 |
| Markdown（.md） | 原生支持，直接处理 |
| 网页剪藏 | Chrome 扩展一键抓取 |

**方式一：拖拽或选择文件导入**

在左侧边栏切换到「资料源」面板，点击导入按钮或直接将文件拖入窗口。支持多文件同时导入，也支持**文件夹递归导入**。

**方式二：Chrome 扩展网页剪藏**

1. 从 Releases 下载 llm-wiki-extension-*.zip
2. 解压后打开 chrome://extensions，启用「开发者模式」
3. 点击「加载已解压的扩展程序」，选择解压后的文件夹
4. 安装完成后，浏览任意网页时点击扩展图标，内容会被自动提取并转换为 Markdown

**方式三：Source 文件夹自动监听**

在设置中配置 raw/sources/ 文件夹监听后，你用其他方式在此文件夹下新增、修改或删除文件，LLM Wiki 会自动检测变更并触发摄入或删除清理。

### 三、知识摄入：LLM 自动构建 Wiki

这是 LLM Wiki 最核心的能力。导入资料后，系统会自动进入**两步思维链摄入流程**：

```
第一步（分析）：LLM 阅读资料 → 结构化分析
├─ 提取关键实体、概念、论点
├─ 识别与现有 Wiki 内容的关联
├─ 发现与已有知识的矛盾或张力
└─ 给出 Wiki 结构建议

第二步（生成）：LLM 基于分析 → 生成 Wiki 文件
├─ 资料摘要页（YAML frontmatter + 来源链接）
├─ 实体页面、概念页面及交叉引用（[[wikilink]]）
├─ 更新 index.md、log.md、overview.md
├─ 标记需人工审核的项目
└─ 生成深度研究的搜索主题
```

**重要机制：增量缓存**。系统会对每个源文件计算 SHA256 哈希值，如果文件内容未变更，下次启动时自动跳过，不浪费 LLM Token 和时间。

### 四、聊天查询：与知识库对话

在中间聊天区域，你可以像和 AI 对话一样提问。LLM 会自动执行检索流程：分词搜索 → 图谱扩展 → 上下文组装 → 生成回答。

聊天功能支持多对话管理、引用参考面板、重新生成、保存到 Wiki、思考过程展示等。

### 五、知识图谱：看见知识之间的连接

左侧切换到图谱面板，你会看到一个交互式的**知识关系网络**。

- **节点**代表每个 Wiki 页面，按类型或 Louvain 社区着色
- **边**代表页面之间的关联，颜色从绿到灰表示关联强度
- **节点大小**表示该页面的链接数

v0.4.11 新增图谱搜索功能，输入关键词自动定位并高亮对应节点。

**图谱洞察**：系统自动分析「惊奇连接」（跨领域意外关联）和「知识空白」（孤立页面、连接薄弱社区）。

### 六、深度研究：主动填补知识盲区

一键启动深度研究：LLM 自动生成搜索主题 → 多搜索引擎查询 → 综合生成 Wiki 研究页面 → 自动交叉引用现有知识 → 进入两步摄入流程。

### 七、审核队列：人机协作的质检环节

LLM 遇到需要人工判断的情况会存入审核队列，你只需点击确认或修改即可——不阻塞摄入流程。

### 八、Lint 检查：保持知识库健康

定期扫描：孤立页面、失效链接、index 不一致、内容矛盾或过时信息。

### 九、API 服务：知识库开放接入（v0.4.11）

```bash
# 健康检查（无需 Token）
curl http://127.0.0.1:19828/api/v1/health

# 混合搜索
curl -H "Authorization: Bearer YOUR_TOKEN" \
 -H "Content-Type: application/json" \
 -d '{"query":"机器学习","topK":5}' \
 http://127.0.0.1:19828/api/v1/projects/current/search

# 读取页面内容
curl -H "Authorization: Bearer YOUR_TOKEN" \
 "http://127.0.0.1:19828/api/v1/projects/current/files/content?path=wiki/concepts/transformer.md"

# 获取知识图谱数据
curl -H "Authorization: Bearer YOUR_TOKEN" \
 http://127.0.0.1:19828/api/v1/projects/current/graph
```

所有接口默认只读，数据不出本机，安全可控。
