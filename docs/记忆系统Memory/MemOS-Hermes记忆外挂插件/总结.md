# MemOS - Hermes 记忆外挂插件

> 总结使用: MiniMax M2.5

## 背景

Hermes Agent 是 Nous Research 开源的自住 AI Agent 框架，GitHub 10万+ Star。

核心问题：Agent 记得住，但记得乱。多个记忆堆积，过时的、重复的、矛盾的内容混在一起，记忆库变成大杂烩。

## MemOS 插件核心能力

### 存得聪明

四步处理：语义分片 → LLM 摘要 → 向量化 → 智能去重

**智能去重**是最有价值的部分：不是简单的文本比对，而是让 LLM 判断是新内容、重复内容还是更新。

例子：先说减肥，后说放弃。智能合并为一条记录，保留更新历史。

### 找得准

Hermes 原生：SQLite 文本搜索，关键词对不上就搜不到。

MemOS 插件：混合检索引擎（全文搜索 + 向量语义搜索）+ 融合排序 + 时间衰减 + 相关性过滤。

### 主动预检索

每轮对话开始时，系统自动用最新消息预检索相关记忆注入上下文，未命中时提示 Agent 主动搜索。

## 特点

- 完全本地运行，数据不上云
- 开源地址：https://github.com/MemTensor/MemOS/tree/main/apps/memos-local-plugin
