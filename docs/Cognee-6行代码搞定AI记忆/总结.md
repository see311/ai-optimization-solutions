# Cognee - 6行代码搞定AI Agent记忆

> 总结使用: MiniMax M2.5

## 核心定位

16K Star 的开源知识引擎，给 AI Agent 构建完整的持久化记忆系统。GitHub: https://github.com/topoteretes/cognee

## 核心创新

传统 RAG 的痛点：上下文断裂、检索不精准。

Cognee 的方案：向量搜索 + 图数据库结合，文档既可按语义检索，又可按关系连接，形成真正的统一记忆层。

## ECL 管道架构

```
Extract（提取） → Cognify（构建知识图谱） → Load（加载到图数据库+向量数据库）
```

## 双层次记忆

| 层次 | 说明 |
|------|------|
| 会话记忆 | 快速缓存，后台同步到图 |
| 永久记忆 | 知识图谱持久化存储 |

## 四大核心 API

```python
import cognee

# 永久存储（同时执行 add + cognify + improve）
await cognee.remember("Cognee turns documents into AI memory.")

# 存储到会话记忆
await cognee.remember("User prefers detailed explanations.", session_id="chat_1")

# 查询，自动选择最佳搜索策略
results = await cognee.recall("What does Cognee do?")

# 删除数据
await cognee.forget(dataset="main_dataset")
```

## 自动路由检索策略

| 策略 | 说明 |
|------|------|
| TEMPORAL | 时间感知的图搜索 |
| FEEL | 情感感知的检索 |
| SEMANTIC | 纯语义搜索 |
| GRAPH | 纯图遍历 |
| HYBRID | 混合模式 |

## 框架集成

**Claude Code**：插件自动捕获工具调用到会话记忆，会话结束时同步到永久知识图谱。

**Hermes Agent**：配置 `memory.provider: cognee` 即可启用。

## 总结

Cognee 用 6 行代码实现了传统 RAG 难以做到的统一记忆层，向量+图双引擎驱动，是 AI Agent 记忆系统的利器。
