# 文章总结

## 核心要点

本文深度解析了Anthropic官方CLI工具Claude Code的底层架构与工作原理，主要涵盖以下五大核心模块：

### 1. Agent系统（任务执行大脑）
- 主Agent与子Agent协同工作，支持Fork模式和指定subagent_type模式
- 子Agent可继承或独立主Agent上下文，实现任务高效拆分
- 三大行为约束：Never delegate understanding、Don't peek、Don't race

### 2. Prompt系统（行为准则手册）
- 采用"数组拼接+缓存分级"设计，优化API调用成本
- 静态内容全局缓存，动态内容会话内memoize
- CLAUDE.md作为User Message注入而非System Prompt

### 3. Memory系统（六层持久化记忆）
- **层级1 Auto Memory**：跨会话核心记忆自动提取
- **层级2 Session Memory**：单会话结构化笔记
- **层级3 AutoDream**：跨会话离线记忆巩固
- **层级4 Agent Memory**：角色分域持久记忆
- **层级5 Team Memory**：团队共享记忆
- **层级6 CLAUDE.md**：用户手动维护规则
- 四种记忆类型：user/feedback/project/reference

### 4. Context Window管理（四级渐进压缩）
- Level 1 Snip Compact：裁剪历史消息
- Level 2 Micro Compact：压缩工具结果
- Level 3 Context Collapse：上下文折叠（ANT-only）
- Level 4 Auto Compact：全量摘要压缩

### 5. Hooks系统（扩展插件机制）
- 支持25+种Hook事件类型
- 四种Hook类型：command/prompt/agent/http
- 六级来源优先级加载机制

## 核心价值

Claude Code的核心优势在于"智能协同、持续学习、灵活扩展"，通过这五大模块的协同工作，成为开发者不可或缺的智能编码伙伴。
