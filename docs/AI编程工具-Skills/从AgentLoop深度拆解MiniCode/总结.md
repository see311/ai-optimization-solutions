# 从Agent Loop深度拆解Mini Code，看懂Claude Code极简内核实现逻辑

**execute执行机制：**
- 模型多类型响应分层处理：thinking block思考块、progress进度文本、普通assistant文本、tool calls工具调用、特殊异常响应五大类
- 标准化工具调用执行链路：通过ToolRegistry统一管理，内置全局异常捕获
- 批量并行处理多条工具调用请求，支持人工介入优雅处理

**cleanup收尾机制：**
- 循环内部收尾：定义六种回合终止形态（等待用户、无人工介入、正常结束、重试耗尽、步数超限、状态同步）
- 循环外部收尾：权限清除、会话消息覆盖、持久化保存、UI状态恢复、悬浮工具清理

**compact上下文分层压缩机制：**
- 轻量化无模型压缩：MicroCompact(50%)、SnipCompact(70%)、Tool Result Storage
- 大模型智能压缩：Context Collapse(75%)、Auto Compact（临界溢出）
- 手动压缩命令支持：/compact、/snip、/collapse
