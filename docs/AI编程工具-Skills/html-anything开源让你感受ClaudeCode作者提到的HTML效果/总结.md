# html-anything 开源！让你感受 Claude Code 作者提到的 HTML 效果！

## 核心要点

### 1. 项目背景
- Anthropic 的 Claude Code 团队宣布内部文档不再写 Markdown，直接写 HTML
- 核心理念：Markdown 是写给写作者看的，HTML 才是给读者看的

### 2. html-anything 是什么
- nexu-io 团队发布的开源项目（团队还有 40k+ star 的 open-design）
- 专门为 Agent 时代打造的 HTML 编辑器
- 让本地 AI Agent 帮你把任何内容转换成专业级 HTML

### 3. 核心亮点
- **75 套 Skill 模板**：覆盖杂志文章、Keynote 演示、简历、海报、小红书卡片、推文卡片、Web 原型、数据报告、视频分镜等 9 种交付场景
- **自动识别 18 种 Code Agent CLI**：Claude Code、Cursor Agent、OpenAI Codex、Gemini CLI、GitHub Copilot CLI、Qwen Coder、Aider 等
- **零 API Key**：复用已有的 Agent 会话，边际成本为 $0

### 4. 多平台一键发布
- **微信公众号**：CSS 内联，粘贴即用
- **X/微博/小红书**：自动渲染 2× 高 DPI PNG
- **知乎**：LaTeX 公式自动处理
- **下载**：支持单文件 HTML 或高 DPI PNG

### 5. 技术特性
- 支持 11 种文件格式：.md、.txt、.csv、.tsv、.xlsx、.json、.sql、.yaml、.html、.png、.jpg
- SSE 流式渲染
- 沙箱化预览

### 6. 快速上手
```bash
git clone https://github.com/nexu-io/html-anything
cd html-anything
pnpm install
pnpm dev
```

## 总结
html-anything 把 Markdown 降格为写作过程的中间状态，让 HTML 回归给人类阅读的最终形态。核心价值：**你的 Agent 写代码，你专注内容**。
