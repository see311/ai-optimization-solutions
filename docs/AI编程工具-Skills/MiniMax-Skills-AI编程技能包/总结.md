# MiniMax Skills - AI 编程技能包

> 总结使用: MiniMax M2.5

## 核心定位

MiniMax 官方开源的生产级开发技能包，GitHub 3.8K Star。为 AI 编码助手（Claude Code、Cursor、Windsurf、OpenCode）设计，让 AI 输出质量对标大厂资深工程师。

## 核心技能包

### frontend-dev - 前端开发
React / Next.js + Tailwind CSS + Framer Motion/GSAP 动画 + MiniMax 媒体生成 API + AIDA 文案框架 + p5.js/Three.js

### fullstack-dev - 全栈开发
REST API、认证流程（JWT/OAuth）、SSE/WebSocket 实时功能、SQL/NoSQL 数据库集成、生产加固检查清单

### android-native-dev - Android 原生
Kotlin / Jetpack Compose、Material Design 3、自适应布局、Gradle 配置、无障碍支持（WCAG）、性能优化

### ios-application-dev - iOS 开发
UIKit/SwiftUI、SnapKit、iOS 导航模式、Dynamic Type、Dark Mode、无障碍支持、Apple HIG 合规

### shader-dev - GLSL Shader
ray marching、SDF 建模、流体模拟、粒子系统、程序化生成、光照算法、ShaderToy 兼容

### 办公神器
| 工具 | 功能 |
|------|------|
| gif-sticker-maker | 照片转 GIF 贴纸（Funck Pop 风格） |
| minimax-pdf | PDF 生成/填充/重新格式化 |
| pptx-generator | PPT 生成/编辑/读取 |
| minimax-xlsx | Excel 创建/读取/编辑/验证 |
| minimax-docx | DOCX 创建/编辑/验证 |

## 安装方式

**Claude Code**: `claude plugin marketplace add https://github.com/MiniMax-AI/skills`
**Cursor**: `git clone` 到 `~/.cursor/minimax-skills`
**Codex**: `git clone` 到 `~/.codex/minimax-skills`
**OpenCode**: `git clone` 到 `~/.minimax-skills`

项目地址：https://github.com/MiniMax-AI/skills
