# mattpocock/skills 核心要点

## 项目定位
- **60,000+ GitHub Stars** 的开源项目
- 将数十年软件工程经验封装为 16-17 个可执行 Skill
- 被誉为 Claude Code Skills 的"npm 时刻"
- 作者：Matt Pocock（TypeScript 领域专家，参与 Next.js、TurboPack）

## 设计哲学
- **小巧（Small）**: 单一职责，易于理解
- **易调整（Adjustable）**: 可根据项目需求定制
- **可组合（Composable）**: 多个 Skill 灵活组合
- **模型无关**: 不绑定任何 AI 提供商，任何 Agent 都能用

## 核心 Skill 分类

### 需求分析阶段
- `/grill-me`: AI 提问 → 人类回答 → AI 确认 → 写代码
- `/grill-with-docs`: /grill-me 增强版，建立统一语言 (Ubiquitous Language)

### 开发阶段
- `/tdd`: 测试驱动开发，垂直切片红绿重构
- `/improve-codebase-architecture`: 防止架构腐化

### 测试阶段
- `/diagnose`: Bug 系统排查六步法（复现→最小化→假设→插桩→修复→回归）

### 维护阶段
- `/caveman`: 简化代码，保持简洁

## 安装使用
```bash
npx skills@latest add mattpocock/skills
```
