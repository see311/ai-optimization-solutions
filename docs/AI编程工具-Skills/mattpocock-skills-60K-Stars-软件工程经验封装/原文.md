# mattpocock/skills: 60K+ Stars 的软件工程技能库

## 项目概述

[mattpocock/skills](https://github.com/mattpocock/skills) 是一个由 TypeScript 领域专家 Matt Pocock 发起的开源项目，已获得 **60,000+ GitHub Stars**。该项目将数十年软件工程经验蒸馏为 16-17 个可执行的 Skill，为 AI 注入软件工程之魂。

## 作者背景

Matt Pocock 是 TypeScript 领域的权威专家，曾参与 Next.js、TurboPack 等知名开源项目。他的核心理念是：**将软件工程最佳实践封装为 AI 可执行的 Skill**，让任何 AI 编码 Agent 都能遵循专业工程标准。

## 核心设计哲学

### 三大原则

1. **小巧（Small）**: 每个 Skill 专注于单一任务，便于理解和调整
2. **易调整（Adjustable）**: 开发者可以根据项目需求定制 Skill 行为
3. **可组合（Composable）**: 多个 Skill 可以灵活组合形成完整工作流

### 独特优势

- **不依赖特定模型**: 不绑定任何 AI 提供商，任何 AI 编码 Agent 都能使用
- **基于工程经验**: 每个 Skill 都经过实战验证，源自真实的软件工程实践
- **Claude Code Skills 的"npm 时刻"**: 就像 npm 为 JavaScript 带来包管理，这个项目为 AI 编程带来了技能管理

## 17 个核心 Skill

### 需求分析阶段

| Skill | 功能 | 核心流程 |
|-------|------|---------|
| `/grill-me` | 写代码前对齐需求 | AI 提问 → 人类回答 → AI 确认 → 写代码 |
| `/grill-with-docs` | 建立统一语言 (UBiquitous Language) | /grill-me 增强版，结合文档进行需求澄清 |

### 开发阶段

| Skill | 功能 | 核心流程 |
|-------|------|---------|
| `/tdd` | 测试驱动开发 | 垂直切片的红绿重构循环 |
| `/improve-codebase-architecture` | 防止架构腐化 | 持续审视和改进代码结构 |

### 测试阶段

| Skill | 功能 | 核心流程 |
|-------|------|---------|
| `/diagnose` | Bug 系统排查 | 复现 → 最小化 → 假设 → 插桩 → 修复 → 回归 |

### 维护阶段

| Skill | 功能 |
|-------|------|
| `/caveman` | 简化代码，保持代码简洁 |

## 四环节对应

```
需求分析 ────── 开发 ────── 测试 ────── 维护
    │             │           │           │
  /grill-me    /tdd      /diagnose    /caveman
/grill-with-                   
    docs
```

每个 Skill 对应软件开发的特定环节，形成完整的开发周期覆盖。

## 安装与使用

### 快速安装

```bash
npx skills@latest add mattpocock/skills
```

### 使用方式

安装后，可以直接在 Claude Code 等 AI 编程工具中使用这些 Skill：

```
/grill-me        # 开始需求澄清
/tdd             # 启动 TDD 开发模式
/diagnose        # 开始 Bug 诊断
```
