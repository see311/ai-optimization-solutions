# Book2Skill：PDF转Claude Skills的文档技能编译器

## 核心定位

**pdf2skill**（又称 Book2Skill）是一个"文档转技能编译器"，能够将PDF文档中的知识自动转化为AI助手可直接调用的结构化技能包。与传统PDF提取工具不同，它不仅提取文本，更能理解文档的逻辑关系并生成可复用的Skills。

## 五大核心技术模块

1. **文档解析**：PDF转结构化文本，处理目录、标题层级、表格和图表
2. **语义拆解**：按语义密度智能拆分，识别核心概念、操作步骤、异常分支
3. **逻辑建模**：自动建立知识点依赖关系（前置条件、异常分支、并行关系）
4. **技能封装**：输出标准skill文件，包含触发条件、执行逻辑、输入输出格式
5. **路由生成**：自动生成技能索引，使AI能根据问题自动匹配相关技能

## Claude Code Skills三层架构

| 层级 | 加载时机 | Token成本 | 内容 |
|------|----------|-----------|------|
| 元数据层 | 启动时始终加载 | ~100 tokens | YAML frontmatter（name、description） |
| 详细指令层 | Skill触发时加载 | < 5k tokens | SKILL.md 主体的流程与指引 |
| 附加脚本层 | 按需访问 | 几乎无限制 | 脚本文件内容不进入上下文 |

## 三大常见误区

| 误区 | 错误理解 | 实际差异 |
|------|----------|----------|
| PDF总结 = pdf2skill | 都是让AI读PDF | 总结是一次性消费，pdf2skill是永久可复用 |
| Skills = 快捷指令 | 预设几个常用命令 | Skills采用三层渐进式披露，避免上下文浪费 |
| 所有PDF都适合 | 一键转换高质量技能 | 方法论书籍★★★★★，扫描版PDF★★☆☆☆ |

## 适用场景判断

- ✅ **强烈推荐**：技术文档、操作手册、行业报告（★★★★★）
- ✅ **推荐**：学术论文（★★★★☆）
- ⚠️ **不推荐**：扫描版PDF（★★☆☆☆）
- ❌ **不适用**：小说、文学类（★☆☆☆☆）

## 快速上手

1. 访问 pdf2skills.memect.cn 上传PDF
2. 等待2-15分钟处理完成
3. 下载 skills.zip 并解压
4. 导入到 Claude Code 的 ~/.claude/skills/ 目录
5. 重启Claude Code即可使用
