# Alumnium AI E2E Testing Framework

## Core Positioning
Alumnium is an AI-native E2E testing library supporting Playwright/Selenium/Appium with natural language instructions.

## Key Points

### 1. Three Command APIs
- do: describe execution steps
- check: verify results  
- get: extract data

### 2. Internal Agent Architecture
- PlannerAgent: decomposes goals into steps
- ActorAgent: converts steps to tool calls
- Accessibility Trees: cross-platform UI representation

### 3. Multi-LLM Support
Claude, GPT, Gemini, Llama, DeepSeek, Mistral with reasoning model support.

### 4. MCP Server
Connect with Claude Code via Model Context Protocol.

## Applicable Scenarios
- Test engineers reducing assertion writing workload
- Teams needing better test coverage with lower maintenance
- Cross-platform (Web + Mobile) testing
