# Kami - AI文档排版利器

## 核心定位

**Kami** 是一套专为 AI Agent 设计的文档设计系统与排版约束语言（4.6K Star），由开源作者 tw93 开发，隶属于"Kaku（写代码）、Waza（练习惯）、Kami（交付文档）"工作方法论的最后一环。

## 核心价值

用一套跨文档的硬约束替代随意的样式漂移，让 AI 输出从"每次像不同人排的"变成"每次像同一套设计系统排的"。

## 主要功能

| 功能 | 说明 |
|------|------|
| 多类型模板 | One-Pager、Long Doc、Letter、Portfolio、Resume、Slides 等 |
| 内嵌图表 | SVG 图表（架构图、流程图、柱状图等），减少外部依赖 |
| 多语言支持 | 中文（仓耳今楷 02）、英文（Charter）、日文（YuMinchi） |
| 低门槛触发 | 通过 Claude Code Skill 分发，自然语言即可触发 |
| 品牌固化 | 配置文件固化个人信息，提高多轮产出一致性 |

## 设计规则

1. **底色与情绪**：暖米色背景，避免纯白刺眼
2. **字体约束**：单一 serif 字体，字重固定
3. **面向 Agent**：规则简单到 AI 能稳定执行

## 适用场景

- 职场商务输出（方案、提案、推荐信）
- 研究分析材料（研报、白皮书）
- 个人求职（简历、作品集）
- 演讲汇报（幻灯片）
