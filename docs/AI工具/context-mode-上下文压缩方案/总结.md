## context-mode：GitHub 2 天暴涨 13k

context-mode 是一个 MCP Server，专门解决 AI 编程 Agent 在长对话中"上下文爆炸"的问题。该项目在 GitHub 上线仅 2 天就获得了 13,000+ Stars，增长速度惊人。

### 核心问题与解决方案

文章首先分析了 AI 编程助手的四个核心问题：

1. **上下文污染**：30 分钟对话后，40% 上下文是垃圾数据（Playwright 快照 56KB、GitHub issues 59KB）
2. **对话压缩后失忆**：模型删除的是"正在改什么文件"这类关键信息
3. **输出 token 浪费**：Agent 写一堆废话，实际上只需要结果
4. **跨平台割裂**：各工具各自为政，没有统一上下文管理

context-mode 的解决方案是将原始数据拦截下来，压缩存进 SQLite，模型只看到结果摘要。

### 核心数据：98% 上下文压缩

这是官方给出的核心指标：
- 之前：47 次 Read() = 700 KB
- 使用后：ctx_execute() = 3.6 KB
- 压缩率：99.5%，平均节省 98% 上下文空间

### "Think in Code"哲学

context-mode 改变了 Agent 的工作方式——从"读取一切"变成"执行+获取结果"。模型不再需要处理大量原始数据，而是专注于生成和执行代码。
