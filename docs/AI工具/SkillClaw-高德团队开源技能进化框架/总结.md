## 核心要点

### 项目简介

SkillClaw 是由高德地图机器学习团队（AMAP-ML）开源的**技能集体进化框架**，旨在让 AI 智能体从每次交互中自动学习、积累技能，并在跨设备、跨智能体、跨团队之间共享，实现集体进化。

### 四大核心亮点

1. **零干预的自动进化**：双循环架构（任务循环 + 进化循环），对用户完全透明
2. **超广泛的框架兼容性**：支持 Hermes、Claude Code、OpenClaw、Codex、QwenPaw 等主流框架
3. **集体进化的魔力**：团队经验共享，避免重复踩坑
4. **技能质量自动提升**：自动去重、优化、归档，保持技能库高质量

### 技术架构

三个核心组件：
- **Client Proxy**：本地 API 代理，拦截请求、记录会话、同步技能
- **Workflow Evolve Server**：3 阶段 LLM 工作流（Summarize → Aggregate → Execute）
- **Agent Evolve Server**：基于 OpenClaw 的智能体驱动方案

三者共享存储层（OSS/S3/本地）和技能格式（SKILL.md）。

### 快速使用

```bash
# 安装
git clone https://github.com/AMAP-ML/SkillClaw && cd SkillClaw
bash scripts/install_skillclaw.sh

# 配置并启动
skillclaw setup
skillclaw start

# 技能管理
skillclaw skills pull    # 下载共享技能
skillclaw skills push    # 上传本地技能
skillclaw skills sync    # 双向同步
```
