# 高德团队开源力作火了！继 OpenClaw 后，集体进化 AI 项目出圈

2026-05-08 11:58·不秃头程序员

在 AI 智能体领域，有一个现象一直困扰着我们：

每次使用 Agent 时，总会遇到各种问题，然后花了半天找到了解决方案，但这些经验往往只停留在当前会话，下次换个场景或换个设备，一切又得从零开始。

团队协作时更是如此，张三踩过的坑，李四还得再踩一遍，时间和精力都浪费在了重复试错上。

最近，来自 AMAP-ML（高德地图的机器学习团队）推出了一个开源项目，完美解决了这个问题。

他们给它起了个生动的名字叫 **SkillClaw** 。这个项目的核心理念很简单：让智能体从每次交互中自动学习、积累技能，然后让这些技能在跨设备、跨智能体、甚至跨团队之间共享，实现**集体进化** 。

# 什么是 SkillClaw？

SkillClaw 是一个专门为多用户智能体生态系统设计的**技能集体进化框架** 。

简单说，它能从真实交互数据中自动提炼可复用的技能，去重、优化、归档，然后通过云端共享给整个智能体集群，让所有智能体都能共享这些沉淀下来的经验。

在 WildClawBench 基准测试中，SkillClaw 显著提升了 Qwen3-Max 在真实场景下的表现——不是靠更大的模型，而是靠更聪明的经验积累。

最棒的是，使用起来超级简单。装好之后，你只需要像往常一样跟智能体对话就行，技能进化全在后台静默完成，零额外操作。

# 核心亮点

**1、零干预的自动进化**

SkillClaw 采用了一个巧妙的**双循环架构** ：

- **任务时间循环** ：你跟智能体正常对话，完成任务

- **进化循环** ：每次任务完成后，SkillClaw 会在后台自动运行，从真实交互中提取、去重、改进技能

整个过程对用户完全透明，你不需要做任何额外操作，技能库就在不知不觉中持续进化。

**2、超广泛的框架兼容性**

SkillClaw 原生支持几乎所有主流的 Agent 框架：

- Hermes (NousResearch)

- Claude Code (Anthropic)

- OpenClaw

- Codex (OpenAI)

- QwenPaw

- IronClaw、PicoClaw、ZeroClaw、NanoClaw、NemoClaw 等等

不管你用的是哪个框架，都能直接对接 SkillClaw。

**3、集体进化的魔力**

SkillClaw 的**集体进化** 机制是最让人眼前一亮的地方：

- 团队里一个人踩过的坑，提炼成技能后，其他人的智能体直接受益

- 不需要重复犯同样的错误

- 技能库随着团队的使用不断优化

**4、技能质量自动提升**

SkillClaw 不是简单地把所有技能堆在一起，而是会自动：

- 去重：多个相似技能自动合并

- 优化：低质量技能自动改进

- 归档：让技能库保持高质量，不会变成垃圾堆

这解决了一个长期困扰用户的问题——技能库越用越大、越用越乱的痛点。

# 技术架构

SkillClaw 由三个核心组件组成：

**① Client Proxy（客户端代理）**

这是一个本地 API 代理（/v1/chat/completions, /v1/messages），拦截智能体请求，记录会话数据，与共享存储同步技能。

**② Workflow Evolve Server（工作流进化服务器）**

这是一个固定的 3 阶段 LLM 工作流：

- **Summarize（总结）** ：读取会话数据

- **Aggregate（聚合）** ：识别重复模式

- **Execute（执行）** ：进化或创建技能并写回

**③ Agent Evolve Server（智能体进化服务器）**

这是一个基于 OpenClaw 智能体驱动的替代方案，能直接读取会话、分析模式，完全自主地进化技能文件。

这三个组件共享同一个存储层（Alibaba OSS / S3 / 本地文件系统）和技能格式（SKILL.md），完全可互换。

# 快速上手

客户端 / 本地开发：

\`\`\`
git clone https://github.com/AMAP-ML/SkillClaw && cd SkillClaw
bash scripts/install_skillclaw.sh
source .venv/bin/activate
\`\`\`

服务器部署（安装两个服务器入口）：

\`\`\`
bash scripts/install_skillclaw_server.sh
source .venv-server/bin/activate
\`\`\`

仅 Agent 进化服务器需要：

\`\`\`
npm install -g openclaw
\`\`\`

配置并启动客户端代理

\`\`\`
export OPENAI_BASE_URL="https://your-api-gateway/v1"
export OPENAI_API_KEY="sk-..."

skillclaw setup
skillclaw start
skillclaw status
skillclaw config show
\`\`\`

启动进化服务器，SkillClaw 提供了两个进化服务器，选一个：

工作流进化服务器：

\`\`\`
skillclaw-evolve-server --port 8787 --interval 300 \
  --storage-backend oss \
  --oss-endpoint "$EVOLVE_STORAGE_ENDPOINT" \
  --oss-bucket "$EVOLVE_STORAGE_BUCKET" \
  --group-id my-group
\`\`\`

智能体进化服务器：

\`\`\`
skillclaw-agent-evolve-server --port 8787 --interval 300 --no-fresh \
 --storage-backend oss \
 --oss-endpoint "$EVOLVE_STORAGE_ENDPOINT" \
 --oss-bucket "$EVOLVE_STORAGE_BUCKET" \
 --group-id my-group
\`\`\`

技能管理

\`\`\`
skillclaw skills pull # 下载共享技能
skillclaw skills push # 上传本地技能
skillclaw skills sync # 双向同步
skillclaw skills list-remote # 浏览共享技能
\`\`\`

SkillClaw 最近还添加了一个双语仪表盘，可以用以下命令启动：

\`\`\`
skillclaw dashboard sync
skillclaw dashboard serve
\`\`\`

打开 http://127.0.0.1:3791 就能看到：

- 本地技能与共享官方版本的对比

- 候选验证任务和当前状态

- 已发布的共享技能和版本历史

- 技能更新背后的本地和共享会话
