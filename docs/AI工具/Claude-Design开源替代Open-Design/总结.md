# Claude Design 开源替代品 Open Design

## 项目概述

**Open Design** 是由 nexu.io 创始人 Tom Huang 开源的 Claude Design 平替项目，开源仅 5 天即斩获 18.2K 标星，被称为"Claude Design 的真正开源杀手"。

## 核心价值

- **开源免费**：完全开源，数据本地存储，不被任何平台锁定
- **利用现有工具**：不造新的 AI 代理，让已有的编码代理（Claude Code、Codex、Cursor 等）变身设计引擎
- **完整复刻体验**：结构化提问流程 + 品牌设计系统约束 + 实时 Todo 流 + 五维自省批判机制

## 核心亮点

| 功能 | 详情 |
|------|------|
| 设计系统 | 129 套品牌级 Design Systems（含 Linear、Stripe、Vercel、小红书等） |
