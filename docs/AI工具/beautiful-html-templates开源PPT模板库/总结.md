## 核心要点

### 项目简介
**beautiful-html-templates** 是一个包含 32 套 HTML 幻灯片模板的开源库（1.1K Star），由 Zara Zhang 和 Claude（Anthropic）联合开发，采用 MIT 协议。

### 解决的问题
- 普通人用 AI 做 PPT，常常得到"AI 味"很重的页面：字体乱、配色辣眼睛
- 大多数工具选模板靠随机，视觉方向不靠谱
- 非设计同学很难快速产出"看起来专业"的 slides

### 核心功能

**1. 32 套系统化设计模板**
- 完整的 HTML + CSS + JavaScript，零依赖、单文件
- 打开浏览器即可演示
- 覆盖多种场景：Soft Editorial（暖色文学风）、8-Bit Orbit（像素游戏风）、Retro Windows（Win95复古风）、Studio（黑底荧光黄）、Signal（正式商务风）等

**2. AI 智能匹配模板**
- 通过 index.json 元数据注册表标注每套模板的 mood、tone、formality、density 等维度
- 用户用自然语言描述需求 → AI 分析场合、受众、情绪 → 从32套中筛选3个最合适候选 → 用户选定 → AI 生成完整文稿

### 核心价值
把 **AI 与设计系统** 连接起来：你负责说清楚"讲什么、对谁讲、什么场合"，AI 负责把"好看"的部分标准化、可调度、可自动化。
