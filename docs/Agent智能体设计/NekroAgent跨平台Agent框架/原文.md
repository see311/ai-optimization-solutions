# 【开源-agent】NekroAgent：开源跨平台多用户 Agent 框架，支持 QQ/Discord/Minecraft/Bilibili 等多平台接入

一句话介绍：面向多人互动场景的跨平台 Agent 框架，支持多种聊天平台接入，可构建高智能聊天机器人。

NekroAgent（KroMiose/nekro-agent）是由 KroMiose 开源推出的跨平台 Agent 框架，专为多用户聊天场景设计。该项目集成 Claude Code 沙盒执行、工作区编排、长期记忆、结构化 MCP 管理和可视化控制台等核心模块，支持 QQ、Discord、Telegram、Minecraft、BilibiliLive、微信、Email 和 SSE 等多种平台接入。用户可基于该框架构建具备代码执行、工具调用、插件协作和复杂任务处理能力的高智能聊天机器人，适用于社区运营和 AI 应用开发场景。

◆ 多平台支持：QQ、Discord、Telegram、Minecraft、BilibiliLive、微信等多平台统一接入

◆ Claude Code 沙盒：AI 拥有独立代码执行环境，运行安全隔离

◆ 长期记忆模块：跨会话持久化记忆，Agent 上下文理解能力更强

◆ MCP 协议支持：结构化工具管理，扩展性强，可接入各类插件

◆ 可视化控制台：实时状态推送与监控，Bot 运维简单直观

◆ 面向多用户聊天场景，适合社区运营者和 AI 应用开发者快速构建智能 Bot
