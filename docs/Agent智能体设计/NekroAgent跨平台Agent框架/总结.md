# NekroAgent：开源跨平台多用户 Agent 框架

## 核心定位
NekroAgent 是由 KroMiose 开源的跨平台 Agent 框架，专为多用户聊天场景设计，支持多种聊天平台接入，可构建高智能聊天机器人。

## 核心特性

### 多平台支持
- 支持 QQ、Discord、Telegram、Minecraft、BilibiliLive、微信、Email、SSE 等多种平台统一接入
- 一套框架覆盖主流社交和通讯平台

### Claude Code 沙盒
- AI 拥有独立的代码执行环境
- 沙盒隔离保障运行安全

### 长期记忆模块
- 跨会话持久化记忆能力
- 增强 Agent 上下文理解能力

### MCP 协议支持
- 结构化工具管理
- 强扩展性，可接入各类插件

### 可视化控制台
- 实时状态推送与监控
- Bot 运维简单直观

## 技术架构亮点
- **工作区编排**：支持复杂任务的工作区管理
- **多用户聊天**：面向多人互动场景设计
- **工具调用与插件协作**：完整的工具生态

## 适用场景
- 社区运营：构建智能社区助手
- AI 应用开发：快速构建智能 Bot
