# Qoder 工程实践：Harness Engineering 指南

## 核心要点

### 1. 问题本质：Agent 看不见

AI Agent 执行任务时常见问题：
- 架构约定无法跨会话保持
- 生成的代码不符合团队规范
- 没有自动验证，全靠人肉检查
- 上下文窗口被错误日志塞满后"失忆"

**关键洞察**：Agent 不够聪明是表象，真正问题是它"看不见"——看不见代码库的架构决策、层级约束、命名规范。

### 2. 核心思路： Harness Engineering

**核心原则**：与其教 Agent 怎么做，不如让它自己验证做得对不对。

- 靠代码、linter、测试保证正确性，而非 LLM 直觉
- 机械检查不会出错、不会遗忘、不会被上下文压缩
- 就像 CI/CD 对人类开发者的作用——自动拦截问题

### 3. 仓库是 Agent 的操作系统

| 类比 | 人 | Agent |
|------|-----|-------|
| CPU | 推理能力 | LLM 推理能力 |
| 操作系统 | - | Harness |
| 硬盘/内存 | 文件系统 | 仓库架构 |

**四条关键原则**：
1. **仓库是唯一事实来源** — 所有知识必须编码到仓库中（版本化、跟着代码走）
2. **AGENTS.md 是地图不是手册** — ~100 行索引，详细内容放在 docs/ 按需加载
3. **约束只管架构边界** — 层级编号系统，高层可 import 低层，反之不行
4. **人设计系统** — 价值从"写出正确代码"变为"设计让 Agent 可靠产出的环境"

### 4. 层级依赖架构

```
Layer 0: types/       → 纯类型定义，无内部依赖
Layer 1: utils/        → 工具函数，仅依赖 Layer 0
Layer 2: config/       → 配置，依赖 Layer 0-1
Layer 3: core/services/→ 业务逻辑，依赖 Layer 0-2
Layer 4+: api/cli/ui/  → 接口层，依赖 Layer 0-3，彼此不互相引用
```

### 5. 验证体系

**验证类型**：
- **lint-deps**：依赖方向检查（核心）
- **lint-quality**：代码质量规则（单文件≤500行、结构化日志等）
- **verify**：端到端功能验证

**验证顺序**：`build → lint-arch → test → verify`

**事前验证优于事后修复**：
- 违反在 50 行后被抓 → 修复代价约 10 次 tool call
- 写代码前先问"这样做合法吗" → 只需 2 次交互

### 6. 上下文管理：最贵的资源

**核心原则**：中等复杂度以上的任务，**协调者绝不写代码**。

**两层 Agent 架构**：
- **协调者（Coordinator）**：只管规划、委派、汇总，一行代码都不碰
- **执行者（子代理）**：每次从干净上下文开始，干完就释放

**模型分级使用**：
| 任务类型 | 模型选择 | 原因 |
|----------|----------|------|
| 改 typo | Haiku | 快、便宜 |
| 复杂重构 | Opus/Codex | 深度推理 |
| 代码检索 | Flash | 速度快 |

### 7. 交叉 Review

- 用**不同模型**做 review（避免思维盲区重叠）
- 嵌入时机：编码完成 → 机械验证通过 → Review → 接受/修改
- 成本约为编码成本的 10-20%
- 发现的问题可编码为新的 lint 规则

### 8. Harness 自我进化

**反馈循环**：
```
Agent 执行 → 验证抓到问题 → Critic 分析模式 → Refiner 更新规则 → 下一个 Agent 受益
```

**三种记忆**：
- **情景记忆**：具体教训（如 macOS 符号链接问题）
- **程序记忆**：成功操作步骤（如"添加 API 端点的五步流程"）
- **失败记忆**：供 Critic 分析用

**轨迹编译**：同一类任务被成功执行 3+ 次 → 编译成确定性脚本（如 `make add-endpoint`）

### 9. 落地步骤

**最小起步**：
1. 今天：创建 AGENTS.md
2. 本周：添加 lint-deps 脚本
3. 本月：搭完整验证管道
4. 之后：开启 Critic → Refiner 反馈循环

**新项目 vs 老项目**：
- 新项目：creator 直接生成全套基础设施
- 老项目：creator 扫描代码库、推断层级映射、生成反映现状的文档
