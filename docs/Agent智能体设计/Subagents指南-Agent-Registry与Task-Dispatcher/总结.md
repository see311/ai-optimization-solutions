# Subagents指南：Agent Registry + Task Dispatcher 多智能体协作秘籍

本文系统讲解了LangChain官方文档中的Subagents（子代理）模式，这是一种中心化的多智能体协作架构。核心要点包括：

**核心特性：**
- 集中控制：主代理（Supervisor）作为唯一总指挥，所有任务路由必须经过主代理
- 无直接用户交互：子代理只负责执行具体任务，不与用户直接交互
- 子代理即工具：通过标准的Tool Calling机制被主代理调用
- 支持并行执行：单轮对话可同时调用多个子代理

**两种工具暴露模式：**
- Tool per Agent：每个子代理独立包装成工具，适合少量子代理场景
- Single Dispatch Tool：统一参数化工具调用所有子代理，推荐用于大规模协作

**Agent Registry + Task Dispatcher系统架构：**
- Agent Registry存储所有已注册的子代理
- Task Dispatcher作为统一调度入口
- 主代理通过工具调用动态调度子代理

**上下文工程关键：**
- 子代理规格定义决定主代理调度决策
- 需明确子代理职责、能力范围、输入输出格式
- 支持同步与异步两种执行模式
