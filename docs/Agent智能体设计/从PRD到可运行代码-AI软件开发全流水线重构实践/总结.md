# 从PRD到可运行代码，AI软件开发全流水线的重构与实践

## 核心要点

### 1. 行业困局：AI写代码≠全流程落地

当前AI代码生成的瓶颈不在于模型能力，而在于**全链路断链**：
- **需求端断层**：PRD文档是自然语言，机器无法精准解析，导致代码生成先天带偏差
- **流程碎片化**：只覆盖"代码生成"单点，其他环节仍需人工兜底
- **协同全靠人工**：产品、架构、测试、运维各环节AI无法衔接
- **无工程化保障**：生成的代码无法直接接入企业研发体系
- **交付链路断裂**：最后一公里仍需工程师全流程返工

### 2. 九层分层架构

| 层级 | 职责 | 核心能力 |
|------|------|---------|
| 用户层 | 需求统一入口 | 文本/文件/语音/模板4类输入 |
| 接入层 | API Gateway | JWT/OAuth2鉴权、限流熔断、多租户路由 |
| 工作流引擎层 | 全流程编排 | Flowable/Temporal，任务管理、进度管理、高可用容错 |
| 事件总线层 | 松耦合通信 | Kafka/RabbitMQ，TASK_CREATED→STEP_FINISHED完整事件流 |
| Agent层 | AI角色化协同 | Planner/Architect/Coder/Tester/Git 5大Agent |
| 执行层 | 真实计算底座 | Codex/Build/Test/Git/Docker 6大执行器+沙箱隔离 |
| 状态与数据层 | 全流程持久化 | PostgreSQL/Redis/对象存储/Git仓库 |
| 实时反馈层 | 全链路可视化 | WebSocket/SSE秒级状态推送 |
| 输出层 | 标准化交付 | GitHub Repo/API文档/CI-CD/Docker镜像 |

### 3. 五大专属Agent设计

```
┌─────────────────────────────────────────────────────┐
│                    事件总线 (Event Bus)               │
│   TASK_CREATED → STEP_STARTED → STEP_FINISHED        │
└─────────────────────────────────────────────────────┘
                         │
     ┌───────────────────┼───────────────────┐
     ▼                   ▼                   ▼
┌─────────┐       ┌─────────┐       ┌─────────────┐
│ Planner │       │Architect │       │   Coder     │
│  Agent  │──────▶│  Agent  │──────▶│   Agent     │
└─────────┘       └─────────┘       └─────────────┘
                                            │
                         ┌───────────────────┤
                         ▼                   ▼
                   ┌───────────┐       ┌─────────┐
                   │  Tester   │──────▶│   Git   │
                   │  Agent    │       │  Agent  │
                   └───────────┘       └─────────┘
```

- **Planner Agent**：PRD结构化解析，消除歧义，输出标准JSON
- **Architect Agent**：技术栈选型、架构设计、模块拆分、接口定义
- **Coder Agent**：Prompt生成、Codex调度、全量代码生成
- **Tester Agent**：自动生成测试用例、执行测试、输出报告、缺陷反馈
- **Git Agent**：仓库克隆、代码提交、PR创建

### 4. 核心架构思想

1. **拒绝单点模型迷信**：大模型只是工具，流程工程化才是体系
2. **角色Agent化**：复刻人类研发协作分工，专业的人做专业的事
3. **分层解耦+事件驱动**：上游不感知下游，能力扩展不改动主链路
4. **企业级底线**：沙箱安全、全链路可观测、状态全程持久化

### 5. 全链路自动化闭环

```
用户输入PRD → 网关认证 → 工作流触发 → Agent协同执行
                                              ↓
GitHub Repo ← 自动提交 ← 测试通过 ← 代码生成
     │
     ├── 可下载代码包
     ├── Swagger API文档
     ├── CI/CD Pipeline配置
     └── Docker镜像
```

### 6. 关键结论

- AI软件开发的未来竞争：**全流水线能力**而非单点代码生成
- 核心是建立完整的、工程化的、**企业级可用的AI研发操作系统**
- 把软件开发从人力密集型工作，变成**工业化流水线生产**
