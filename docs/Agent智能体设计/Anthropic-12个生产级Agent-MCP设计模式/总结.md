## 文章概述

本文系统介绍了 Anthropic 官方发布的 12 个生产级 Agent MCP 设计模式，将这些模式归纳为 5 大类别。

### 5组12个MCP设计模式

**1. 工具交互面（3个模式）**
- 远程优先服务器模式：MCP Server 应按远程标准设计，适合跨环境复用
- 按意图组织工具模式：按用户意图而非 API endpoint 暴露工具
- 薄交互面模式：用 search + execute 覆盖大量 API（如 Cloudflare 2个工具覆盖2500个端点）

**2. 交互语义（3个模式）**
- 内联 UI 模式：工具返回可交互界面而非文字描述
- 引导式输入模式：Form Mode 让用户补充结构化信息
- 外部跳转交接模式：URL Mode 处理敏感流程（OAuth、支付）

**3. 认证凭证流（2个模式）**
- 可发现认证模式：CIMD 让客户端自动发现认证方式
- 凭证托管到 Vault 模式：凭证生命周期由平台统一管理

**4. 上下文经济（2个模式）**
- 按需加载工具模式：Tool Search 可减少 85% 工具定义 tokens
- 程序化工具调用模式：在沙箱中处理结果，减少 37% token 使用

**5. 打包分发（2个模式）**
- 插件打包模式：Skills、MCP Server、hooks 统一打包分发
- 服务器分发 Skills 模式：Server 不仅提供工具，还分发使用指南

### 核心观点

生产级 Agent 的难点不在于能否调用工具，而在于能否安全、稳定、低成本地连接到真实系统。MCP 的真正价值是让每个系统都能为 Agent 提供一个更稳定、更安全、更可复用的产品交互面。
