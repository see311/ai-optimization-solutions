# PaddleOCR - 75.8k Star 国产 OCR 神器

> 总结使用: MiniMax M2.5

## 核心定位

百度飞桨开源的 OCR 工具集，把图片和 PDF 变成结构化、LLM 能直接用的数据。

## 三大产品线

| 产品 | 功能 | 特点 |
|------|------|------|
| PP-OCRv5 | 多语言文字识别 | 12MB 超轻量，支持 111 种语言 |
| PaddleOCR-VL-1.5 | 复杂文档解析 | 0.9B 参数，94.5% 准确率超越 GPT-4o |
| PP-StructureV3 | 版面分析和表格还原 | PDF/图片转 Markdown/JSON |

## 技术架构

三层架构：
- **底层**：PP-OCR 系列 - 基础文字检测和识别
- **中层层**：PP-Structure 系列 - 版面分析，输出带坐标的结构化数据
- **顶层**：PaddleOCR-VL 系列 - 端到端文档理解

## 核心创新

**PaddleOCR-VL-1.5 的混合架构：**
- 视觉编码器：NaViT 风格动态分辨率
- 语言模型：ERNIE-4.5-0.3B 中文优化轻量模型
- 布局分析模块：PP-DocLayoutV3 先布局后理解

**Real5-OmniDocBench 评测基准**：叠加 5 种真实场景物理畸变（扫描噪声、纸张弯曲、拍摄倾斜、屏幕翻拍、光照变化），鲁棒性更强。

## 应用场景

1. **RAG 系统文档预处理**：PDF 转 Markdown，保持阅读顺序
2. **发票票据自动化处理**：关键字段提取，配合规则校验
3. **移动端多语言翻译**：拍照 → 识别 → 翻译 → 保留版式

## 快速上手

```bash
pip install paddleocr
```

```python
from paddleocr import PaddleOCR
ocr = PaddleOCR(use_angle_cls=True, lang='ch')
result = ocr.ocr('your_image.jpg', cls=True)
```

支持 Python 3.8–3.12，Linux/Windows/macOS，CPU 和 GPU 均可。

## 总结

PaddleOCR 三条产品线覆盖从基础文字识别到复杂文档理解的完整链路，0.9B 参数在文档解析上超越 GPT-4o，是 RAG 文档预处理的利器。
