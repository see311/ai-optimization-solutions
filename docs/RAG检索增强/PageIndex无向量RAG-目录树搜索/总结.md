## 核心要点

### 1. PageIndex 是什么
- **无向量、基于推理的 RAG 系统**
- 上线不到半年狂揽 **25796 颗星**
- 不用向量数据库、不用人工分块
- 让 LLM 像人类专家一样通过"目录树搜索"检索文档
- 在 FinanceBench 金融问答基准上达到 **98.7% 准确率**

### 2. 传统 RAG 的死穴
- **语义相似 ≠ 实际相关**
- 传统向量 RAG 本质上是"玄学检索器"
- 只在"比远近"，不是在"理解"
- 在金融、法律、医疗等专业领域始终不靠谱

### 3. PageIndex 的工作原理
**两步流程：**
1. **生成目录树结构**：把长文档转换为语义化树形结构，每个节点包含标题、页码、摘要和子节点
2. **基于推理的树搜索**：LLM 推理判断哪个分支最可能包含答案，一层层深入直到找到准确答案

### 4. 四大核心特性
1. **❌ 不用向量数据库**：无需向量嵌入、余弦相似度、ANN搜索
2. **❌ 不用人工分块**：使用文档自然章节结构，无需纠结分块策略
3. **✅ 类人检索**：检索过程与人类读文档找答案完全一致
4. **✅ 可解释可追溯**：每一步都有完整推理路径，清晰可查
