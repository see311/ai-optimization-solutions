## 项目概述

Hyper-Extract 是一款由 LLM 驱动的通用结构化知识抽取开源框架，旨在补齐传统 RAG 缺少复杂关系建模的短板。

## 核心架构

项目采用三层架构设计：
1. **CLI 交互层** — 用户交互入口
2. **核心抽取引擎** — 负责知识抽取逻辑
3. **8 大类强类型知识输出结构** — 结构化输出

## 核心特性

- **原生支持复杂图谱**：区别于传统仅支持二元图谱的工具，原生支持超图、时空融合图，可完整还原多方事件、带时间地点的复杂业务关系
- **全行业标准化模板**：预置全行业标准化抽取模板，开箱即用
- **多模型兼容**：兼容云端 API 与 vLLM 本地私有化模型
- **增量迭代机制**：解决知识库反复全量重建的痛点
- **自然语言检索**：支持用自然语言检索知识资产
- **可视化图谱预览**：提供图谱可视化能力

## 适用场景

- 学术文献梳理
- 金融财报分析
- 企业知识库建设
- GraphRAG 底座开发
