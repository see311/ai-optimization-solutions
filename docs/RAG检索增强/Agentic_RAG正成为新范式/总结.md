# Agentic RAG 正成为新范式

## 核心要点

### 1. 传统 RAG 的瓶颈
- **三环节流程**：检索 → 重排序 → 生成
- **边际递减**：不断优化 embedding、重排序器，增益越来越有限
- **核心问题**：检索与生成割裂，模型无法主动控制检索策略

### 2. Agentic RAG 的核心突破
- **主动检索**：模型自己决定"查什么"、"何时停"
- **循环推理**：推理 → 检索 → 再推理，不断迭代优化
- **降低复杂度**：不再依赖外部向量数据库

### 3. 典型案例
- **Grok Code**：强化学习驱动的代码智能体，检索→分析→修改→验证闭环
- **PageIndex**：长文档上下文索引系统，金融问答准确率达 98.7%

### 4. 关键转变
| 传统 RAG | Agentic RAG |
|---------|-------------|
| 被动查询 | 主动探索 |
| 外部向量库 | 内部上下文索引 |
| 一次性检索 | 循环迭代优化 |
