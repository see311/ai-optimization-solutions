# Corpus2Skill - 告别检索，直接导航企业知识库

> 总结使用: MiniMax M2.5

## 核心问题

传统 RAG 的缺陷：用户提问 → 向量检索 → 拼接收上下文 → LLM 生成答案。LLM 从来看不到知识库全貌。

## 核心方案

**Corpus2Skill 框架**：不要让 Agent 去搜索，给它一张地图，让它自己导航。

### 离线编译阶段

将文档语料库转化为"技能目录树"：

| 步骤 | 操作 |
|------|------|
| 文档加载与向量化 | 读取所有文档，生成语义嵌入向量 |
| 迭代层次聚类 | K-Means 聚类，LLM 生成主题摘要，递归聚类直到顶层 ≤ K |
| 标签生成 | 为每个节点生成 2-5 个安全标签（如 wix-commerce） |
| 目录树构建 | 物化为 SKILL.md + INDEX.md + documents.json |

### 在线服务阶段

Agent 通过两个工具完成导航：
- `code_execution`：浏览 SKILL.md 和 INDEX.md
- `get_document(doc_id)`：按 ID 拉取文档全文

## 核心价值

"编译时换查询时"——查询时摆脱对嵌入式检索的依赖，让 LLM 的推理能力真正发挥。
