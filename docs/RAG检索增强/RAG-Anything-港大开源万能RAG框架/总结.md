# RAG-Anything - 港大开源万能 RAG 框架

> 总结使用: MiniMax M2.5

## 核心定位

港大数据智能实验室(HKUDS)开源的 All-in-One RAG 框架，GitHub 1.7万星。能处理 PDF、图片、表格、公式、图表等图文混排文档，让 AI 真正读懂"完整"文档。

## 核心创新

1. **基于 LightRAG**：港大之前的热门项目，底子稳定
2. **集成 MinerU**：专业文档结构识别引擎，完整还原 PDF 版式
3. **双图谱架构**：同时构建跨模态关系图谱 + 文字语义图谱，检索时互相配合
4. **VLM 视觉语言模型**：自动调用视觉模型"看图说话"

## 架构特点

```
文档 → MinerU解析 → 双图谱构建 → LightRAG检索 → VLM增强 → 答案
```

## 三种查询模式

| 模式 | 说明 |
|------|------|
| Pure Text | 纯文字查询，简单问答 |
| VLM Enhanced | 视觉增强，答案在图里时自动看图 |
| Hybrid | 混合检索，结合图谱结构+语义匹配，效果最好 |

## 快速上手

```bash
pip install raganything
```

```python
from raganything import RAGAnything

rag = RAGAnything(working_dir="./rag_storage",
    llm_model_func=...,   # 语言模型
    vision_model_func=...) # 视觉模型

await rag.aprocess_document("./report.pdf")
result = await rag.aquery("核心结论是什么？", mode="hybrid")
```

## 适用场景

- 学术研究：论文图表对比、方法差异总结
- 金融分析：财报 K 线图、对比表数据提取
- 医学影像：CT 片、化验单、诊断图表
- 企业知识库：技术手册、SOP 流程图
- 教育：教材公式、例题、插图索引
- 技术文档：API 文档、电路图、架构图

## 软硬件要求

- Python 3.10+
- 内存 8GB 起步(大型 PDF 需 16GB+)
- 不绑定特定大模型，支持 OpenAI/Claude/Gemini/Ollama/vLLM
- 本地视觉模型需 8GB+ 显存 GPU
