# codegraph-rust 纯 Rust 实现的代码 GraphRAG 核心要点

## 项目定位

codegraph-rust 是一个 100% Rust 实现的代码知识图谱构建工具，通过 AST + FastML 解析和 SurrealDB 图数据库，为 AI 代码助手提供深层代码理解能力。

## 核心技术

| 组件 | 技术方案 | 优势 |
|------|---------|------|
| 解析引擎 | AST + FastML | 深度代码结构理解 |
| 图数据库 | SurrealDB | 高效图数据存储 |
| AI 协议 | MCP | 主流工具无缝对接 |
| 索引分层 | fast/balanced/full | 灵活权衡速度和精度 |

## 7 大 Agentic 工具

CodeGraph 提供的工具覆盖代码分析全场景：

1. **语义搜索** - 跨文件语义级代码查找
2. **依赖分析** - 传递依赖与耦合度分析
3. **调用链追踪** - 完整执行路径可视化
4. **架构分析** - 整体结构与设计模式识别
5. **API 分析** - 接口表面与消费者映射
6. **上下文构建** - 精准上下文聚合
7. **语义问答** - 跨领域深度推理

## 与传统 RAG 的区别

| 维度 | 传统 Embedding RAG | CodeGraph GraphRAG |
|------|-------------------|-------------------|
| 索引方式 | 文本块向量化 | 代码结构图谱 |
| 关系理解 | 无 | 函数/模块/调用关系 |
| 返回内容 | 相似文本片段 | 代码+关系上下文 |
| 分析能力 | 搜索 | 搜索+分析+推理 |

## 应用价值

- 为 AI 代码助手提供**真正的代码理解**，而非简单文本匹配
- 通过 MCP 协议快速集成到 Claude Code、Cursor 等主流工具
- 支持 14 种编程语言的深度分析
- 分层索引设计兼顾效率与精度
