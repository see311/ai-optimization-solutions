# 【开源-RAG】codegraph-rust：纯 Rust 实现的代码 GraphRAG，AST 高速解析 + SurrealDB，打造 AI 代码助手超强大脑

codegraph-rust（Jakedismo/codegraph-rust）是由 Jakedismo 推出的 100% Rust 实现代码 GraphRAG 项目。它通过极快的 AST 解析配合 FastML 进行代码语义分析，以 SurrealDB 作为图数据后端，构建代码知识图谱并支持语义搜索。项目通过 MCP 协议与 Claude Code、Cursor、Codex 等主流 AI 代码助手无缝对接，为 AI Agent 提供更丰富的代码上下文，显著提升代码分析、检索和理解能力，适用于 AI 代码助手开发、代码搜索引擎优化和代码知识管理场景。

## 核心特性

- **100% Rust 实现**：内存安全、性能优异，代码解析速度极快
- **AST + FastML 解析**：深度理解代码结构，语义分析更精准
- **SurrealDB 后端**：专为图数据设计，代码知识图谱存储更高效
- **MCP 协议支持**：无缝对接 Claude Code、Cursor、Codex 等主流 AI 工具
- **高效上下文管理**：为 AI Agent 提供更丰富的代码上下文，提升分析质量
- **GraphRAG 能力**：代码知识图谱构建，语义搜索更智能

## 核心架构

### 图 + Embeddings = 真正的理解

大多数语义搜索工具创建 embeddings 就结束了。CodeGraph 构建了一个真正的知识图谱。

### 索引分层

索引是分层的，可以在速度/存储和图丰富度之间选择。默认为快速模式。

| Tier | 功能 | 典型用途 |
|------|------|---------|
| fast | 仅 AST 节点 + 核心边 | 快速索引，低存储 |
| balanced | LSP 符号 + 文档/富化 + 模块链接 | 良好的 Agent 结果 |
| full | 所有分析器 + LSP 定义 + 数据流 + 架构 | 最大精度/丰富度 |

### Agentic 工具

CodeGraph 提供 7 个专门的 Agentic 工具：

1. **agentic_code_search** - 多步语义搜索与 AI 综合
2. **agentic_dependency_analysis** - 传递依赖与耦合度分析
3. **agentic_call_chain_analysis** - 调用链追踪
4. **agentic_architecture_analysis** - 架构分析与模式识别
5. **agentic_api_surface_analysis** - API 表面分析
6. **agentic_context_builder** - 上下文聚合
7. **agentic_semantic_question** - 深度语义推理

## 支持的语言

支持 Rust、Python、TypeScript/JavaScript、Go、Java、C++、C、Swift、Kotlin、C#、Ruby、PHP、Dart 等 14 种编程语言。
