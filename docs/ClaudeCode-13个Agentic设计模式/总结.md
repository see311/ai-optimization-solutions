# Claude Code - 13个Agentic设计模式

> 总结使用: MiniMax M2.5

## 四大分类

| 分类 | 解决的问题 | 模式数量 |
|------|-----------|----------|
| 记忆与上下文 | 记得住、记得清、不浪费 | 5个 |
| 工作流与编排 | 有条理、不混乱 | 3个 |
| 工具与权限 | 能做事、不闯祸 | 3个 |
| 自动化 | 少出错、省力气 | 2个 |

## 一、记忆与上下文（5个模式）

### 1. 持久化指令文件模式
在项目根目录放置 `agent-instructions.md`，Agent 启动时自动加载规则，避免每次重复交代。

### 2. 作用域上下文组装模式
按"组织级-用户级-项目根目录-父目录-子目录"层级加载规则，子目录覆盖父目录。适用于 Monorepo 项目。

### 3. 分层记忆模式
- **索引层**：最核心信息，始终在上下文（几百行内）
- **活跃层**：当前任务相关，按需加载
- **持久层**：完整历史，存储在磁盘/数据库

### 4. 记忆整合模式（Dream Consolidation）
定期"垃圾回收"：去重、删旧、解决冲突、结构重组、索引优化。

### 5. 渐进式上下文压缩
分层压缩：最新层保留细节 → 近期层轻量总结 → 远期层深度压缩 → 历史层仅保留摘要。

## 二、工作流与编排（3个模式）

### 6. 探索-规划-行动循环
```
探索(只读) → 规划(与用户对齐) → 行动(执行)
```
先搞清楚情况，再规划方案，最后动手，避免"急于动手"导致的错误。

### 7. 上下文隔离子智能体
每个阶段由独立子Agent负责，拥有独立上下文，避免"上下文污染"。

### 8. 分支-合并并行模式
拆分为互不依赖的子任务，由子Agent并行处理（git worktree机制），最后合并结果。

## 三、工具与权限（3个模式）

### 9. 渐进式工具扩展
按需开放工具：初始阶段只开放基础工具 → 任务复杂时逐步开放高级工具。

### 10. 命令风险分类
```
低风险 → 自动放行（cat、npm run build）
中风险 → 提示确认（修改配置、删除单个文件）
高风险 → 直接拦截（rm -rf、sudo）
```

### 11. 工具契约模式
为每个工具定义清晰的"契约"：输入参数、输出格式、使用限制、异常处理。Agent 调用前先读契约。

## 四、自动化（2个模式）

### 12. 自动化重试模式
可恢复错误（网络波动、文件占用、超时）自动重试；不可恢复错误（权限不足、命令错误）提示用户。

### 13. 操作护栏模式
- **路径护栏**：禁止操作核心目录
- **命令护栏**：禁止高危命令（rm -rf）
- **内容护栏**：禁止修改关键配置

## 落地建议

1. **循序渐进**：先记忆模式 → 再工作流 → 最后工具与自动化
2. **按需调整**：小型项目不需要复杂模式
3. **持续优化**：收集反馈，迭代调整
4. **重视安全**：权限控制、风险防范、日志记录
