# TigerFS - PostgreSQL 挂载为文件系统

> 总结使用: MiniMax M2.5

## 核心定位

将 PostgreSQL 数据库挂载为文件系统，通过标准 Unix 工具（ls、cat、find、grep）直接与数据库交互，无需 API 或 SDK。MIT 许可。

## 核心思路

```
智能体 → 文件系统 → PostgreSQL（ACID 保障）
```

AI 智能体喜欢文件系统而非复杂 API，用熟悉的 Unix 工具操作结构化数据。

## 两种使用模式

### 文件优先
- 将文件（Markdown 等）整理到目录中
- 利用原子写入与自动版本控制
- 通过移动文件表示任务状态（待办→进行中→已完成）
- 现有工具（编辑器、命令行）无需修改即可处理

### 数据优先
- 挂载已有 PostgreSQL 数据库
- 用 Unix 工具浏览数据
- 路径中可包含过滤/排序条件，自动转为 SQL 查询

## 技术实现

- **Linux**: FUSE 挂载
- **macOS**: NFS 挂载
- 每个文件对应一条数据库行
- 支持事务保障与并发访问
- 特殊目录（.build、.info、.export）用于元数据

## 适用场景

- 小型数据集（配置、上下文、任务状态）
- AI 智能体工作流
- 多智能体/用户并发访问
