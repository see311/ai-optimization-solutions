用AI写前端，界面总有股"AI味"？
用 Cursor / Claude Code 写前端，生成的页面是不是总逃不开这几样：Inter 字体、白底紫渐变、圆角卡片套卡片… 一眼就是 AI 写的 😅
	
分享 7 个我实测好用的网页设计 Skill，装上之后 AI 写出来的界面质感直接拉满
	
先治审美——教 AI 什么是好设计
	
❶ frontend-design
周安装 150K+，装机必备。教 AI 做设计前先想清楚：给谁用？什么调性？怎么让人记住？自带反"AI审美"机制。
	
❷ ui-ux-pro-max
内置 50+ 设计风格、161 种配色、57 组字体搭配，堪称设计百科全书，适合需要快速做设计决策的场景。
	
❸ frontend-design（pbakaus/impeccable）
在 Anthropic 官方 Skill 基础上深度扩展，自带 17 个设计指令（/audit 审查、/polish 润色、/distill 精简…），支持几乎所有主流 AI 编程工具
	
❹ interface-design
专为仪表盘、管理面板、SaaS 工具打造。要求 AI 写代码前先回答「谁在用？要完成什么？给人什么感觉？」，拒绝模糊的"简洁现代"。
	
再落地——让好设计变成代码
	
❺ tailwind-design-system
Tailwind v4 专属，周安装 17.6K+。没有它 AI 写 Tailwind 就是类名乱堆，装上后按设计系统规范输出，间距、色彩、响应式全都有章法
	
❻ shadcn
AI 最爱用的组件库，但默认风格已经成了"AI味"标配。配合上面的美学 Skill 自定义主题后，同样是 shadcn 组件，风格完全不同
	
❼ frontend-design-system
完整的 Design Token 体系 + 8px 间距规范 + WCAG 无障碍标准，让 AI 产出的界面有统一设计语言。
	
💡 搭配建议：
→ 做落地页：❶ + ❻
→ 做 SaaS 后台：❹ + ❻
→ 极致美学控：❸ + ❷ + ❺
→ 个人作品集/博客：❶ + ❷ + ❻
→ 企业官网：❸ + ❼

npx skills add  --skill
