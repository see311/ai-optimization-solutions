# 7个AI前端设计Skill - 去除AI味

> 总结使用: MiniMax M2.5

## 问题

用 Cursor / Claude Code 写前端，生成的页面总是：
- Inter 字体
- 白底紫渐变
- 圆角卡片套卡片
→ 一眼 AI 写的

## 解决方案：先治审美，再落代码

### 第一部分：教 AI 做设计（4个Skill）

| Skill | 用途 | 特点 |
|-------|------|------|
| frontend-design | 周安装150K+，装机必备 | 教AI做设计前先想清楚：给谁用？什么调性？怎么让人记住？自带反AI审美机制 |
| ui-ux-pro-max | 设计百科全书 | 50+设计风格、161种配色、57组字体搭配 |
| frontend-design（pbakaus/impeccable） | Anthropic官方Skill深度扩展 | 17个设计指令（/audit审查、/polish润色、/distill精简…），支持所有主流AI编程工具 |
| interface-design | 仪表盘/SaaS/管理面板专用 | 要求AI写代码前先回答「谁在用？要完成什么？给人什么感觉？」，拒绝模糊的"简洁现代" |

### 第二部分：让好设计变成代码（3个Skill）

| Skill | 用途 | 特点 |
|-------|------|------|
| tailwind-design-system | Tailwind v4专属，周安装17.6K+ | 没有它AI写Tailwind就是类名乱堆，装上后按设计系统规范输出 |
| shadcn | AI最爱用组件库 | 默认风格已成AI味标配，配合美学Skill自定义主题后完全不同 |
| frontend-design-system | 完整设计语言 | Design Token体系 + 8px间距规范 + WCAG无障碍标准 |

## 搭配建议

| 场景 | 推荐组合 |
|------|----------|
| 落地页 | frontend-design + shadcn |
| SaaS后台 | interface-design + shadcn |
| 极致美学控 | frontend-design(pbakaus) + ui-ux-pro-max + tailwind-design-system |
| 个人作品集/博客 | frontend-design + ui-ux-pro-max + shadcn |
| 企业官网 | frontend-design(pbakaus) + frontend-design-system |

## 安装方式

所有Skill在 skills.sh 上找到：
```bash
npx skills add <skill-name>
```
